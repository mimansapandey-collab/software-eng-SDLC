## 📌 1. Project Overview

This project presents a case study on the **Software Development Life Cycle (SDLC)** through the design and proposed development of an Online Library Management System (OLMS) for a college library.

The case study explores how software engineering principles can transform a traditional library that relies on manual registers and card catalogues into an organised, efficient and computerised system.

It covers all six phases of SDLC, compares different software development models, and demonstrates how the Agile (Scrum) methodology can be applied to a real-world scenario.

## 🎯 2. Objectives

- Understand the concept and importance of SDLC.
- Study the Planning, Requirement Analysis, Design, Implementation, Testing, and Maintenance phases.
- Compare Waterfall, Agile and Spiral development models.
- Apply SDLC concepts to an Online Library Management System.
- Prepare software design diagrams, including Flowcharts, Use Case Diagrams and DFDs.
- Understand the importance of testing, documentation and maintenance in software development.

## ⚙️ 3. Problem Statement

Traditional library management systems often depend on handwritten registers and manual record-keeping.

This creates several challenges:

- Time-consuming book searches.
- Errors in issue and return records.
- Manual fine calculation.
- Difficulty generating reports.
- Risk of losing or damaging important records.

**Proposed Solution:** An Online Library Management System that computerises library operations and provides faster book searches, accurate transactions, automatic fine calculations and organised record management.

## ✨ 4. Key Features

The proposed Online Library Management System includes:

- **User Registration & Login:** Secure access for library members.
- **Book Search:** Search books by title, author or subject.
- **Book Management:** Add, update and delete book records.
- **Issue & Return:** Manage book borrowing and returning.
- **Book Renewal:** Allow members to request loan renewals.
- **Automatic Fine Calculation:** Calculate fines for late returns.
- **Reports Generation:** Generate reports for librarians and administrators.
- **Data Management:** Maintain organised member, book and transaction records.
